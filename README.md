## 3D格子動捕角色

1. 開啟 `character-builder.html`，使用預設128格圓頭Q版素體，或在製作頁載入角色JSON。
2. 編輯頭、左手、左腳、右手、右腳。左右以角色本身為準；手／腳含整段手臂／腿。軀幹有獨立旋轉支點。
3. 在「基準點／彎折點」調整頭、軀幹、四肢支點，以及手肘、膝蓋位置；下段為小臂／小腿，含手掌／腳掌。用四肢面板預覽彎曲，不用重做JSON。
4. 編輯左右眼、嘴型、左右眉的獨立狀態。同五官不同狀態可覆蓋，跨五官會阻擋並顯示不可覆蓋。
5. 在「測試」選手動、本機鏡頭或VMC。鏡頭可選「面部＋頭部」或「全身＋面部＋頭部」，啟動後觀察骨架與各肢狀態。校正按下3秒後取樣。
6. 在「輸出」設定檔名、頁籤名、頁籤文字動畫，再輸出HTML／GLB／JSON或三格式ZIP。

| 偵測 | 內容 |
| --- | --- |
| 左眼／右眼 | 各自睜眼、微睜眼、閉眼 |
| 嘴型 | 張嘴、微張、閉嘴嘴角上、閉嘴嘴角下 |
| 左眉／右眉 | 各自抬高、復位 |
| 頭部 | 前後仰、左右轉、左右歪 |
| 全身鏡頭 | 軀幹、四肢上段、手肘／膝蓋以下的下段 |

全身模式仍保留面部與頭部偵測；全身入鏡時臉較小，細節精度可能降低。四肢獨立判斷，不要求雙肩雙髖全部入鏡；仍需看見欲追蹤的關節。沒有手指、脊椎彎折、腳掌局部追蹤、地面位移或腳底鎖定。VMC目前只接面部／頭部，尚未接身體骨骼。

製作頁有模型格線、XYZ單層／全層格線、顏色與透明度、三軸輔助線、其他格淡化、參考圖尺寸與透明度。選格XYZ及顏色在預覽下方工具列；QA／WS／ED調整三軸，輸入文字時不應觸發選格快捷鍵。

尺寸支援64／128／256／512；基礎素體固定128。支點與彎折資料保存於JSON。彎折採平面切分上下段，未做蒙皮或補縫，大角度可能露出切口或穿插。

### 匯出格式

- **JSON**：可繼續編輯的動捕角色專案，含方格、表情、支點、彎折與設定。範例為 `examples/base-character-128.json`。
- **HTML**：獨立角色頁，含設定與鏡頭偵測。左鍵點角色開設定、右鍵旋轉、中鍵或滾輪縮放；透明背景只留角色。
- **GLB**：當下造型及姿勢的定型幾何、頂點色；不含面捕程式、VRM或蒙皮骨架。

頁籤動畫是 `document.title` 文字逐格切換，並非影片圖示。格式可用 `{title}`／`{frame}`；每行一格，最多32格，每格120字，間隔100～5000ms。favicon為🏃‍♂️，不隨文字動畫改變。瀏覽器背景頁籤可能降速。

## 3D格子固定角色／場景

使用附件原版工具，保留其建模、插入圖片、動畫、鏡頭、外觀、按鍵、檔案、GLB輸出及圖片輸出頁籤。

1. 設定32／64／128／256／512網格、XYZ位置、顏色及透明度，新增／套用、刪除或復原方塊。
2. 使用插入圖片與網格作為建模參考；調整外觀、鏡頭與按鍵。
3. 在檔案頁匯入／匯出模型JSON；動畫頁可新增、複製、排序幀或批次匯入JSON，設定幀時間、循環／來回及鏡頭。
4. 匯出GLB或圖片；要保留可編輯動畫，另存動畫專案JSON。

這套沒有鏡頭面部／人體追蹤。其模型JSON為 `voxel-editor-v1`，動畫專案為 `voxel-animation-v1/v2`；與動捕角色的 `ansha-chibi-studio-v1` 不互通，請在原工具載入。單模型匯入最多10萬方塊、20MB，座標為1～N。動畫上限以工具當前驗證為準（目前程式1000幀），效能取決於方塊數及裝置，並非預設可順暢播放的保證。

## v17 辨識資訊取代鏡頭影像
製作頁「測試」、匯出HTML角色頁及桌面應用都改為辨識資訊面板。鏡頭video保留於畫面外供模型取樣，不顯示真人影像，也不繪製原影像上的骨架。辨識面板列出左右眼、嘴型、左右眉、套用校正／鏡像／靈敏度後的頭部三軸角度，以及軀幹與四肢有效狀態。

每個訊號獨立判斷時效：面部1600ms、四肢800ms、軀幹1200ms；逾時顯示中斷／遮擋或空值，不把手動復位表情誤標為已辨識。手動模式清楚標示手動狀態，VMC維持僅面部／頭部。面板不儲存於JSON；匯出HTML清除即時結果再重新初始化。

既有模擬測試新增辨識資訊與逾時檢查，製作頁與角色頁均通過。未在本次重新測試真人攝影機或Windows／macOS實機。

## v18 腳部未辨識時不繼承軀幹動捕
全身鏡頭模式下，腿部必須有有效髖／膝／踝完整鏈才更新。每個身體資料包若某腿缺少完整鏈，該腿立即停止更新，不沿用過期的軀幹相對旋轉。
有歷史時，保留最後一次有效腿部的模型世界座標上段及下段矩陣，含髖部位置與膝彎曲；沒有歷史時使用原手動／中立站姿，排除即時軀幹動捕變換。左右腳獨立處理，手部／面部繼續追蹤。這是模型座標姿勢保留，不是新增地面定位或腳底鎖定演算法。
原800ms有效期僅決定目前訊號是否有效；保留姿勢不因1200ms軀幹逾時被清掉。重新取得完整腿部資料即恢復追蹤。停止輸入、切換來源、切換偵測模式或載入角色會clearBody並清除歷史，恢復手動姿勢。
資訊欄顯示「未辨識／維持上一姿勢」或「未辨識／維持站姿」，不可把保留姿勢標成已辨識。暫態矩陣不寫回JSON與手動支點／角度。相機視角操作仍正常影響整個場景。
驗證包括隱藏雙腿但改變肩膀傾斜、單腳踝遺失、全身逾時、無歷史站姿、切換來源清除歷史及既有144組五官／彎折／鏡像測試；製作與角色頁模擬通過。參考使用者影片定位問題，未在本次重新做真人攝影機或桌面平台實測。

## v19 自動維持姿勢與3秒鎖定
輸入／測試分頁新增「偵測不到時維持姿勢（軀幹／四肢）」開關，預設開啟。舊JSON缺欄位亦預設開啟。追蹤不足時保留最後有效的軀幹與四肢模型世界姿勢；沒有歷史則維持手動／中立姿勢。開關關閉後，失效的身體回到手動姿勢；腿部仍不繼承無效即時軀幹而飄動。
新增鎖定範圍：全身（軀幹＋四肢）、僅四肢、軀幹、左手／手肘、右手／手肘、左腳／膝蓋、右腳／膝蓋。按「3秒後鎖定姿勢」後倒數，3秒結束才擷取當下顯示姿勢。沒有辨識資料時可鎖住手動或已保留的姿勢，不宣稱這些是新辨識結果。可分次鎖不同部位；解除鎖定會取消倒數並解除全部鎖定。
頭部與臉部不鎖定。軀幹鎖定後，頭部補償使用鎖定時的軀幹基準，避免新的身體追蹤干擾頭部。每條肢體保存上段與下段世界矩陣，含位置及彎折，不只凍結局部角度。資訊面板顯示「已鎖定」與「未辨識／維持上一姿勢」區別。
settings.holdMissingPose與settings.poseLockScope保存在JSON／輸出HTML；鎖定快照與倒數屬本次工作階段，不寫回JSON、手動支點或手動旋轉。GLB仍烘焙當下顯示姿勢。停止輸入、切換來源／偵測範圍或載入角色會清除快照與取消倒數。
實作：effectiveOverlay／effectiveBody統一挑選手動、追蹤、保留或鎖定軀幹；heldLimbs／heldTorso保存自動保持，poseLocks保存明確鎖定，後者優先。裝飾、角色模型schema與原生視窗設定不變。
已驗證：倒數未到3秒可動、以倒數結束的姿勢取樣、全身鎖定、單肢鎖定、臉部頭部持續、解除後恢復、來源變更取消倒數、自動保持開關與JSON設定。製作頁與角色頁模擬通過；未重新做真人鏡頭或各平台實測。
