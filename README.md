# GLB 方塊製作器

以單一 HTML 編輯單色立方模型，匯入／匯出 JSON，輸出 GLB 與 PNG，並以多個模型幀播放動畫。

## 開啟方式

下載 `GLB_Command_Studio.html`，用支援 WebGL 的瀏覽器開啟。Three.js、鏡頭控制與 GLB 匯出程式已內嵌，核心功能不必另外安裝或啟動伺服器。

## 介面

功能位於底部頁籤，工具區維持固定高度；內容過多時在區內捲動，切換頁籤不會因內容行數不同而推動模型畫面。縱向螢幕亦可使用。

| 頁籤 | 功能 |
| --- | --- |
| 建模 | 網格尺寸、XYZ、顏色、不透明度、新增／套用、刪除、復原、模型預覽、全景與定位 |
| 插入圖片 | 選擇圖片、平面、層數及前後延伸厚度 |
| 動畫 | 多 JSON 匯入、切換幀、新增／複製／刪除／排序、播放與匯出專案 |
| 鏡頭 | 使用此畫面、複製／貼上、貫通所有幀、數值與投影設定 |
| 外觀 | 定位框線、定位線、網格與背景顏色、網格透明度 |
| 按鍵 | 自訂建模快捷鍵 |
| 檔案 | 匯入／匯出目前模型 JSON，以及前往輸出功能 |
| GLB 輸出 | 檔名與輸出 XYZ 軸對應 |
| 圖片輸出 | 六視角／目前視角、正交／透視、尺寸與透明背景 |

## 建模座標與尺寸

- 支援 `32`、`64`、`128`、`256`、`512` 立方。
- XYZ 使用從 `1` 開始的整數；每個方塊都是一格，不可傾斜。
- X：左右，正方向向右。
- Y：前後，正方向向後。
- Z：高低，正方向向上。
- 256 格的網格線每 2 格顯示；512 格每 4 格顯示。選取、編輯與 JSON 座標仍精確到 1 格。
- 空格不會預先建立方塊；512³ 是可用座標範圍，不表示能填滿全部空間。

輸入 XYZ 選取位置後，可以新增／套用方塊。顏色與不透明度變更會立即套用到目前位置，空格也會建立方塊。不透明度在介面使用 `0～100%`，JSON 使用 `0～1`。

選取框保留高亮，其他方塊在編輯模式會黯淡半透明。「模型預覽」會隱藏定位高亮並顯示模型原本顏色與不透明度。

## 快捷鍵

| 按鍵 | 動作 |
| --- | --- |
| A / D | X 減少／增加一格 |
| S / W | Y 減少／增加一格 |
| Q / E | Z 減少／增加一格 |
| 空白鍵 | 套用目前顏色與不透明度 |
| Delete | 刪除目前方塊 |
| Ctrl+Z；Mac 可用 Command+Z | 復原 |

移動鍵可按住連續操作。輸入欄位取得焦點、播放動畫或處理作業時，不會執行建模快捷鍵。可在「按鍵」頁修改八個建模鍵；不可重複，修改後按「套用按鍵」。目前自訂的是單鍵，Ctrl+Z／Command+Z 為固定復原鍵。

## 圖片轉方塊

1. 選擇網格大小與圖片平面。
2. 指定層數，預設為 `size / 2 + 1`。
3. 設定向前、向後厚度，各 `0～8` 格。
4. 按「插入圖片」選檔，直接轉換。

圖片保持比例縮入網格並置中，透明像素略過。所選平面的軸值向前為減少、向後為增加；超出網格部分裁切。兩者都為 0 時只建立一層；向前 2、向後 3 時，最多建立 6 層。

插入會先清除該厚度範圍的既有方塊，再加入圖片結果；透明區域也不保留該範圍舊方塊。支援 PNG、JPEG、WebP、GIF、BMP、AVIF，動畫圖不會轉成逐幀動畫。轉換後仍受每模型方塊數上限限制。

## JSON 匯入與保存

- 「檔案 → 匯入 JSON」可載入單一模型或動畫專案；網格尺寸會依檔案自動切換。
- 「檔案 → 匯出 JSON」只保存目前模型。
- 「動畫 → 多 JSON 匯入」載入多個單模型 JSON 作為幀，加入目前動畫；初始未修改的示範幀會被取代。
- 「動畫 → 匯出動畫專案」保存全部幀、每幀時間、播放選項與鏡頭。
- 單模型格式為 `voxel-editor-v1`；動畫專案為 `voxel-animation-v1`。完整規格見 `AI_JSON_GUIDE.md`。

關閉頁面會要求確認，但不是自動存檔。工作完成請主動匯出 JSON 或動畫專案。

## 動畫

最多 100 幀，各幀保存自己的模型、尺寸與顯示時間。每幀時間可設為 `16～60000 ms`；FPS 控制可設 `1～60`，修改 FPS 會重新設定全部幀的顯示時間。

播放採逐幀切換，沒有骨架、補間或自動產生中間姿勢。總長由每幀 `duration` 相加決定，例如 60 幀 × 500 ms = 30 秒。不要在載入此範例後修改 FPS，否則總長也會改變。

可使用循環、往返播放與時間滑桿。播放前會準備各幀模型；播放時暫停建模操作。

複製幀使用 `原名(1)` 到 `原名(100)` 的第一個未使用編號。再次複製已編號的幀，不會繼續疊加括號；複製編號與整個動畫的幀數上限分別檢查。

## 鏡頭

先用滑鼠或觸控調整模型視角，再切到「鏡頭」按「使用此畫面」，即可讀入目前視角數值。

- 複製鏡頭：保留鏡頭 JSON 在文字欄，並嘗試複製到剪貼簿。
- 貼上鏡頭：將鏡頭 JSON 貼入文字欄，按「貼上鏡頭」，再按「套用鏡頭」。剪貼簿權限不可用時，仍可手動複製貼上文字欄。
- 貫通所有幀：立即把目前欄位中的鏡頭存入所有幀，並套用到畫面。
- 未勾選「各幀獨立鏡頭」時，播放維持同一鏡頭。
- 勾選後，各幀可讀取自己的鏡頭；切換不提供鏡頭平滑補間。

鏡頭頁的數值採製作座標，動畫 JSON 的鏡頭採引擎座標，請依生成規格轉換。

## 輸出

### GLB

輸出目前幀的靜態模型。可設定檔名與三個輸出軸，每個製作軸只能使用一次，可選正負方向。預設對應為 `X ← +X`、`Y ← +Z`、`Z ← −Y`，讓製作時的高度 Z 對應 GLB 的高度 Y。

輸出只包含模型，不含網格與選取線；目前不會把多幀動畫打包成 GLB 動畫。

### PNG

支援 `+X / −X / +Y / −Y / +Z / −Z` 六視角，以及目前視角。六視角以 ZIP 下載，單視角輸出 PNG。寬高各可設 `16～4096` 像素，可選透明背景。

- 正交：相同大小的方塊不會因遠近而改變畫面尺寸，適合 2D 式視圖。
- 透視：近大遠小。

圖片不包含網格和選取高亮。六視角以模型邊界使用一致的取景尺度。

## 容量限制

| 項目 | 上限 |
| --- | --- |
| 每模型 JSON 的 voxels 筆數／編輯方塊數 | 100,000 |
| 動畫幀數 | 100 |
| 可播放動畫的各幀方塊數總和 | 1,000,000 |
| 單模型 JSON 檔案 | 20,000,000 bytes |
| 動畫專案 JSON 檔案 | 200,000,000 bytes |

512³ 空間的全滿模型遠超過限制。大尺寸宜只保留需要的方塊；動畫成本按每幀方塊數累加。以上是程式上限，不保證所有裝置都能以相同速度處理。

## 範例

`MintPumpkin_128_30sec.json`：128³、60 幀、每幀 500 ms，共 30 秒。從「檔案」匯入整份專案，再到「動畫」播放。
